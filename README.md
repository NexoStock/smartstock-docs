# SmartStock - Documentación del Proyecto

Repositorio de documentación del proyecto **SmartStock**, desarrollado por la startup **NexoStock** para el curso **Desarrollo de Aplicaciones Open Source (UPC)**.

## Resumen

SmartStock propone una solución para mejorar la gestión de inventarios en minimarkets y bodegas de barrio, enfocándose en:

- Monitoreo del inventario físico mediante sensores de peso IoT.
- Comparación entre el stock físico y el stock registrado.
- Detección de productos con niveles bajos de stock.
- Generación de alertas para anticipar necesidades de reposición.
- Gestión de la reposición y coordinación con proveedores externos.

Este repositorio contiene el informe del trabajo final, incluyendo investigación, análisis de requisitos, diseño UX/UI, arquitectura de software, implementación, validación y evidencias de los sprints.
